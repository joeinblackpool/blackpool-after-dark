# Blackpool After Dark

A nightlife GeoGuessr for 40 Blackpool venues: walkable Street View, a venue scanner, GPS check-ins,
a Daily Challenge, Pub Crawls and live races with friends.

- **Play it:** https://nintendo.org.uk/ (also https://joeinblackpool.github.io/blackpool-after-dark/) (on a phone, use "Install app" or "Add to Home Screen")
- **The game:** everything is in [`game/`](game/). See [`game/README.md`](game/README.md) for how it plays and what to edit.
- **Android app:** every push builds an APK. Open the **Actions** tab, then the latest "Build Android APK" run, and download it under Artifacts.

Every push to `main` republishes the website automatically.
